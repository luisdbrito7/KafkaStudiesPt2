# Estudos com Apache Kafka

Este repositório reúne códigos e práticas desenvolvidos durante meus estudos sobre **Apache Kafka**, com o objetivo de compreender melhor o funcionamento da comunicação assíncrona e da troca de mensagens entre aplicações.

O aprendizado foi realizado com o auxílio do curso de Kafka da **Fernanda Kipper**, por meio de exercícios práticos e experimentações com as ferramentas utilizadas no desenvolvimento.

## Tecnologias e ferramentas

- **Apache Kafka:** plataforma de mensageria utilizada para a comunicação entre aplicações.
- **Offset Explorer:** ferramenta utilizada para visualizar e acompanhar tópicos, mensagens e outras informações do Kafka.
- **Insomnia:** utilizado para enviar requisições e mensagens durante os testes da aplicação.
- **Java e Spring Boot:** utilizados no desenvolvimento das aplicações e na integração com o Kafka.

## O que estou estudando

- Conceitos fundamentais do Apache Kafka.
- Produção e consumo de mensagens.
- Comunicação assíncrona entre aplicações.
- Criação e utilização de tópicos.
- Integração do Kafka com aplicações Java e Spring Boot.
- Testes e monitoramento de mensagens utilizando ferramentas auxiliares.

## Organização dos repositórios

Este repositório é uma continuação dos meus estudos e complementa outro projeto disponível no meu GitHub. Ambos fazem parte da minha jornada de aprendizado sobre desenvolvimento back-end e mensageria, reunindo diferentes etapas e práticas realizadas durante os estudos.

## Objetivo

Consolidar meus conhecimentos em mensageria e arquitetura de aplicações distribuídas, desenvolvendo uma base prática para a construção de sistemas back-end mais desacoplados e escaláveis.

Este projeto está em desenvolvimento contínuo, acompanhando minha evolução nos estudos de Java, Spring Boot e Apache Kafka.
